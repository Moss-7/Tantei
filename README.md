# たんていミミと ひみつの たからもの

小学一年生向けの宝探しゲームです。探偵のミミを動かして庭を調べ、謎を解いて宝箱を見つけます。

現在遊べるのは次の2話です。

- 1話「おうちと にわ」: あひるを数える、花の並びのきまり、2つの答えを使って宝の場所を掘り当てる
- 2話「がっこう」: 何番目の机かを数える、時計を読む、2つの答えを使ってロッカーを選ぶ

1話をクリアすると2話が遊べるようになります。クリアしたマークを選ぶと、遊ぶ話を選べます。

## 遊び方

`index.html` をブラウザで開きます。ビルドやサーバーは不要です。

- 行きたい場所をタッチ(クリック)するとミミが歩きます。矢印キーと画面の十字ボタンでも動かせます。
- 星のマークに着くと謎が始まります。
- 1つ目と2つ目の答えは「てちょう」に記録され、3つ目の謎で使います。
- 謎の答え(あひるの数、花の色、時計の時間など)は、遊ぶたびに変わります。

## セーブ

タイトル画面の3つのマーク(うさぎ・ねこ・くま)が、それぞれ別のセーブデータです。謎を解くたびに自動で保存されます。データはその端末のブラウザに保存され、「ながおしで けす」で消せます。

## ファイル

- `index.html` 画面の枠組み
- `style.css` 見た目
- `game.js` ゲーム本体(マップ、移動、謎、セーブ、絵の描画)。話ごとの設定は先頭の `STAGE` にまとめています
