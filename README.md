# たんていミミと ひみつの たからもの

小学一年生向けの宝探しゲームです。探偵のミミを動かして庭を調べ、謎を解いて宝箱を見つけます。

全5話です。

- 1話「おうちと にわ」: 池であひるを数える、花壇で次に咲く色を考える、屋根の色と入口の形で小屋をしぼる
- 2話「がっこう」: 黒板の計算を解く、時計を読む、上から何段目・左から何番目のロッカーかを選ぶ
- 3話「こうえん」: 花壇の花をたし算して同じ番号のベンチを探す、看板の暗号を矢印に直して広場を進む、シーソーで重さを比べて果物のバスケットを探す
- 4話「しょうてんがい」: クッキーのひき算の答えで左から何番目の屋台かを探す、数の大小を比べて屋根の色と番号が合う店を探す、2つの手がかりからケーキを食べた動物をしぼる
- 5話「ふしぎな おやしき」: ろうそくで10を作る数を考えて時計の針を合わせる、暗号を本の色の順番に直して本を押す、2つのヒントに合うように箱を並べかえる。最後に5つの宝物がそろう

前の話をクリアすると次の話が遊べるようになります。クリアしたマークを選ぶと、遊ぶ話を選べます。

## 遊び方

`index.html` をブラウザで開きます。ビルドやサーバーは不要です。

- 行きたい場所をタッチ(クリック)するとミミが歩きます。矢印キーと画面の十字ボタンでも動かせます。
- 手紙が届いたら、黄色く光っているものを見に行きます。着くと近くで見る画面が開き、そこで謎を解きます。
- 解いた答えは「てがかりカード」になり、シロの吹き出しに並びます。
- カードを使って場所を探し、そこで「さがす」を押します。見つかるとカギと次の手紙が手に入ります。
- 5話では、カードを使って「しかけ」(時計、本棚、箱)を動かします。
- カードが1枚のときは、正しい場所に立つとカードが光ります。2枚のときは、「さがす」を押すとカードごとに○×が返ります。
- 何度か間違えるとヒントが出て、さらに間違えるか時間がたつと、正しい場所に星が光ります。
- 謎の答え(あひるの数、花の色、時計の時間など)は、遊ぶたびに変わります。

## セーブ

タイトル画面の3つのマーク(うさぎ・ねこ・くま)が、それぞれ別のセーブデータです。謎を解くたびに自動で保存されます。データはその端末のブラウザに保存され、「ながおしで けす」で消せます。

## ファイル

- `index.html` 画面の枠組み
- `style.css` 見た目
- `game.js` ゲーム本体(マップ、移動、謎、セーブ、絵の描画)。話ごとの設定は先頭の `STAGE` にまとめています

## たんていミミ2 なないろの ちず

`mimi2/index.html` を開きます。公開ページは https://moss-7.github.io/Tantei/mimi2/ です。

ミミの宝石が7つのかけらに割れて、町へ飛んでいってしまいました。町の7つの場所で依頼人の困りごとを解決し、地図のかけらを集めて宝石を元に戻します。全7話です。

1作目より手順を減らし、「みる・とく・つかう」だけで遊べる形にしています。

- **みる**: 黄色く光っている物をタッチすると、近くで見る画面が開きます。1話に2回です。
- **とく**: その画面で謎を解くと、答えが「カード」になってシロの吹き出しに並びます。
- **つかう**: カードを手がかりに、マップの上で答えの場所や物をタッチします。

手紙、カギ、てちょう、さがすボタン、十字ボタンはありません。行きたい場所や物をタッチすると、ミミが歩いて調べます。パソコンでは矢印キーでも歩けます。

### 7つの話

| 話 | 場所 | 依頼人 | 謎 |
|---|---|---|---|
| 1 | えき | ペンギン | 時計を読む(なんじ・なんじはん)→ 時刻表で番線を調べる → そのホームをタッチすると電車が来る |
| 2 | としょかん | フクロウ | 本の絵を数えてたし算 → 案内板の数の並びで棚の色を調べる → その色の本棚をタッチ |
| 3 | どうぶつえん | ゾウ | 手紙の暗号を表で読む(みぎ/ひだり)→ バナナのひき算(なんばんめ)→ 2枚を合わせて部屋を選ぶ |
| 4 | うみべ | ウミガメ | 貝がらのたし算(みぎへ なんます)→ ひもの長さ(したへ なんます)→ ヤシの木からマスを数えて掘る |
| 5 | ゆうえんち | アシカ | 風船の並びのきまり(色)→ 雲で半分かくれた窓の形 → 2枚に合うゴンドラを選ぶと、観覧車が回って降りてくる |
| 6 | もり | こりす | 10こずつの袋でどんぐりを数える → 日記の手がかりから家の木をしぼる(論理)→ 分かれ道で大きい数の道を3回選び、おくの木を選ぶ |
| 7 | とけいとう | ネズミ | 集めた6つのかけらを指でつかんで地図にはめる → 出てきた時計を読む(なんじなんぷん)→ レバーで大時計の針を合わせてかねを鳴らす |

7話のあとにエンディング(かけらが宝石に戻り、依頼人みんなが歩いてくる)があります。

- 数や答えの並びは、遊ぶたびに変わります。
- 2回まちがえるとヒントが出ます。最後の「つかう」でまちがえたときは、シロがどこがちがうかを教えます。
- 前の話のかけらを持っていると、地図で次の場所が光って行けるようになります。地図で場所を選ぶと、ミミが道を歩き、虫めがねでのぞきこむ演出のあと話が始まります。

### はじめての時だけ出るもの

- 最初の虫めがねの画面をタッチすると、音が鳴り始めます。
- 宝石が割れて町へ飛んでいくプロローグ(6秒ほど)。
- 各話のはじめの、依頼人との短い会話(3コマ)。

どれも「とばす」で飛ばせます。2回目からは出ません。

### セーブ

タイトル画面の3つのマーク(うさぎ・ねこ・くま)が、それぞれ別のセーブデータです。集めたかけらと、プロローグや会話を見たかどうかを、人ごとに覚えます。データはその端末のブラウザに保存され、「ながおしで けす」で消せます。全部クリアすると、マークに「ぜんぶ クリア!」と出ます。

### テストモード

アドレスの後ろに `?test` をつけると(例: https://moss-7.github.io/Tantei/mimi2/?test )、できている話をすべて地図から選べます。おとなが途中の話を確認するためのものです。

### ファイル

- `mimi2/index.html` 画面の枠組み
- `mimi2/style.css` 見た目
- `mimi2/game.js` ゲーム本体。話ごとの中身(マップ、謎、絵)は `EKI`・`LIB`・`ZOO`・`SEA`・`PARK`・`FOREST`・`TOWER` にまとめ、`STAGES` に並べています
