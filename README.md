# たんていミミと ひみつの たからもの

小学一年生向けの宝探しゲームです。探偵のミミを動かして庭を調べ、謎を解いて宝箱を見つけます。

全5話です。

- 1話「おうちと にわ」: 池であひるを数える、花壇で次に咲く色を考える、屋根の色と入口の形で小屋をしぼる
- 2話「がっこう」: 黒板の計算を解く、時計を読む、上から何段目・左から何番目のロッカーかを選ぶ
- 3話「こうえん」: 花壇の花をたし算して同じ番号のベンチを探す、看板の暗号を矢印に直して広場を進む、シーソーで重さを比べて果物のバスケットを探す
- 4話「しょうてんがい」: クッキーのひき算の答えで左から何番目の屋台かを探す、数の大小を比べて屋根の色と番号が合う店を探す、2つの手がかりからケーキを食べた動物をしぼる
- 5話「ふしぎな おやしき」: ろうそくで10を作る数を考えて時計の針を合わせる、暗号を本の色の順番に直して本を押す、2つのヒントに合うように箱を並べかえる。最後に5つの宝物がそろう

前の話をクリアすると次の話が遊べるようになります。クリアしたマークを選ぶと、遊ぶ話を選べます。

## 遊び方

`index.html` をブラウザで開きます。ビルドやサーバーは不要です。

- 行きたい場所をタッチ(クリック)するとミミが歩きます。矢印キーと画面の十字ボタンでも動かせます。
- 手紙が届いたら、黄色く光っているものを見に行きます。着くと近くで見る画面が開き、そこで謎を解きます。
- 解いた答えは「てがかりカード」になり、シロの吹き出しに並びます。
- カードを使って場所を探し、そこで「さがす」を押します。見つかるとカギと次の手紙が手に入ります。
- 5話では、カードを使って「しかけ」(時計、本棚、箱)を動かします。
- カードが1枚のときは、正しい場所に立つとカードが光ります。2枚のときは、「さがす」を押すとカードごとに○×が返ります。
- 何度か間違えるとヒントが出て、さらに間違えるか時間がたつと、正しい場所に星が光ります。
- 謎の答え(あひるの数、花の色、時計の時間など)は、遊ぶたびに変わります。

## セーブ

タイトル画面の3つのマーク(うさぎ・ねこ・くま)が、それぞれ別のセーブデータです。謎を解くたびに自動で保存されます。データはその端末のブラウザに保存され、「ながおしで けす」で消せます。

## ファイル

- `index.html` 画面の枠組み
- `style.css` 見た目
- `game.js` ゲーム本体(マップ、移動、謎、セーブ、絵の描画)。話ごとの設定は先頭の `STAGE` にまとめています
